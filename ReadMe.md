# JavaScript Calculator 🧮

A simple and interactive calculator built using HTML, CSS, and vanilla JavaScript. This project helps practice JavaScript fundamentals and DOM manipulation.

## ✨ Features

- Addition, subtraction, multiplication, and division
- Interactive calculator buttons
- Clear button to reset calculations
- Responsive user interface
- Real-time display updates

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/hamza001p/javascript-calculator.git
```

### 2. Navigate to the project folder

```bash
cd javascript-calculator
```

### 3. Run the project

Open the `index.html` file in your browser.

## 📚 Learning Objectives

- DOM manipulation
- JavaScript event handling
- Functions and conditional logic
- Handling user input
- Updating the UI dynamically
